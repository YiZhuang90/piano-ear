# 听音钢琴课

手机浏览器里用麦克风听你弹的音，带零基础一步步学琴。课程骨架是拜厄《钢琴基本教程》Op.101：先过几关现代入门（找键、五指热身），再按拜厄的顺序一首首弹，旁边有儿歌加餐。

原书的坡度对今天的初学者偏陡，所以每一关都标了“原书难在哪”和“这里怎么帮”：分手练（另一只手网页替你弹）、先“等你弹”再“跟拍子”、可调速度、只练某几小节并循环、五线谱从不看到淡淡的再到只看谱、配简单伴奏。

- `index.html`：网页本身，不用安装。
- `score.js`：读 MusicXML、按五指位推指法、分手、配伴奏（浏览器和 node 共用）。
- `lessons/curriculum.json`：关卡和每一课；`lessons/beyer/`：拜厄乐谱（MusicXML）。来源和许可见 `lessons/NOTICE.md`。
- `detector.js`：单音音高（YIN）和起音检测。
- `test-detector.js`：用合成钢琴音离线测试，`node test-detector.js`。

识音有两种（设置里“识音方式”可换，会记住）：
- **AI 识别**（默认）：Spotify 的开源模型 Basic Pitch（Apache-2.0，见 `model/NOTICE.md`），在手机浏览器里用 TensorFlow.js（Apache-2.0）每 0.07 秒左右算一次最近 2 秒的声音，能同时听出好几个音，轻声也能听到。按当前这一步该弹的音来打分：和弦要全部按到，琴弦余音和泛音不算错。第一次打开要下载约 1.2 MB（模型约 0.9 MB 加 TensorFlow.js），之后浏览器会缓存。模型加载失败、自检没通过或手机算得太慢，会自动退回简单识别。地址加 `?nntest=1` 可以不用麦克风、用合成琴声测一下这台手机能不能跑、算得多快。
- **简单识别**：`detector.js` 里的 YIN，只听单音；双手同时弹或几个键一起按时，听到其中一个就算对。
- `nnpitch.js`：AI 识别的流式调用、按预期音打分、退回逻辑。

点屏幕琴键要全部按到。麦克风需要 https 才能用，所以放在 GitHub Pages 上。
- `hand3d/`：3D 绑骨右手（模型、动作模块、演示页），可单独复用，见 hand3d/README.md。
- `kids.js`、`kids.css`：儿童版（不用识字）。大人版右上角点“🧸 儿童版”进入，会记住；右上角“家长”按住 1 秒回大人版。地址加 `?kids=1` 直接打开儿童版。语音提示、指法颜色（拇指红、食指橙、中指绿、无名指蓝、小指紫）、每关先示范、弹对放星星、图画地图。
